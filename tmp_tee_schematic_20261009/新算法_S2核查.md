## 图中长度和张量究竟是什么

保留你的 `S₂(2L)` 记号：`L` 数两行重复胞，`2L` 数切口上的 D 维虚键。
蜂窝边长取 1 时，沿 y 的几何周长是 `3L`；按切键数拟合与按几何长度拟合的 α 相差单位换算。
新背景把原来的 `S₂(2L)` 改记作 `S₂(L)`，所以出现 `L/2` 次幂；以下统一恢复前者，转移矩阵取 `L` 次幂。

每个方形 edge 原存储为 `(χ,χ,D²)`，其中 `D²` 的融合顺序是 `ket*D+bra`。
展开后是两条 χ 腿、红绿各一条 D 腿。新背景中的数字 8 是原始 bond dimension=8 的特例。
这里四个 rank-4 `A,B,C,D` 与源码中 rank-3 的同名 bulk 双层张量不同。

```text
沿 y 的第一行：    左 d → A ══ 红/绿 D 腿 ══ B ← 右 c
沿 y 的第二行：    左 a → D ══ 红/绿 D 腿 ══ C ← 右 b
重复 L 次：       左边 A,D,A,D,...；右边 B,C,B,C,...
```

`AB` 是同一行左右两侧的收缩；`DC` 是下一行的收缩。
两条 χ 链沿 y 周期闭合，得到半无限圆柱的一刀熵；它不是一维边界链上一个有限区间的熵。
第7步中最右侧方形、圆柱的腰斩只是绘图方式，数值张量没有被分解或切掉一半。

## 本图所需的实际 code mapping

本图切口交替穿过左 `d(γ),a(β)` 和右 `c(γ),b(β)`。
因此使用 `CTMRG_from_init_to_stop` 返回的 **env1：`T1F,T2A`**；`T1F` 通过 C₃ 代表所需的 `T3D`。
`ab` 来自原始 `(a,b)`；`ba` 来自交换后的 `(b,a)`，两次独立运行。
右侧沿 χ 链的方向与左侧相反，并交换切口 ket/bra 次序以写成矩阵 trace：

```python
A = ab_T1F.reshape(chi, chi, bond_D, bond_D).permute(2, 3, 1, 0)
D = ab_T2A.reshape(chi, chi, bond_D, bond_D).permute(2, 3, 0, 1)
B = ba_T1F.reshape(chi, chi, bond_D, bond_D).permute(3, 2, 0, 1)
C = ba_T2A.reshape(chi, chi, bond_D, bond_D).permute(3, 2, 1, 0)
```

右侧的切口换序已经包含所需转置，不能再额外加共轭。
`correlation_length.obtain_4Ts()` 特意再做一次 `env1→env2`，返回 `T1D,T2C`；它服务于其自身的切口，不能直接代入本图。

## 三行证明：为什么正好是 Tr(ρ²)

记左右周期边界 Gram MPO 为 P、Q；右侧已经采用上述切口腿顺序。
正确的半圆柱 Gram 对应的物理约化密度矩阵非零谱为 `sqrt(P) Q sqrt(P)/Tr(PQ)`。

\[
\operatorname{Tr}\rho^2=\operatorname{Tr}(PQPQ)/[\operatorname{Tr}(PQ)]^2.
\]
\[
\operatorname{Tr}(T_1^L)=\operatorname{Tr}(PQ),\qquad
\operatorname{Tr}(T_2^L)=\operatorname{Tr}(PQPQ).
\]
\[
\boxed{S_2^{\rm CTM}(2L;D,\chi)=-\ln\operatorname{Tr}(T_2^L)+2\ln\operatorname{Tr}(T_1^L).}
\]

`T₁` 的状态空间维数是 `χ²`，`T₂` 是 `χ⁴`。
新背景的 `ABAB→DCDC` 八步 matvec 正是 `T₂` 的精确作用，不必构造完整矩阵。
这是 CTM 圆柱 Rényi 熵构造；完整推导与文献定位见 [数学核查](audit_math.md)。

## 450 GB 下的优势和限制

complex128 一条完整 `T₂` 向量占 `16χ⁴` bytes；保留 m 条 Krylov 向量占 `16mχ⁴` bytes。
输出 χ 腿分批后，work 为 `16D²×batch×χ³` bytes；主要存储与 L 无关。
以下用 D=8、batch=8，并计入额外三条向量、两个 work；GB 为十进制。

| χ | 完整 basis 条数 | basis GB | 主数组粗估 GB |
|---:|---:|---:|---:|
| 64 | 80 | 21.47 | 26.58 |
| 96 | 80 | 108.72 | 127.29 |
| 128 | 80 | 343.60 | 390.84 |
| 144 | 80 | 550.38 | 619.94，超限 |

χ=128 的方案在 450 GB 主存内有安排余量，但 GPU 显存须另计。
一次完整 matvec 为 `4D²(D+1)χ⁵` 次复乘加；D=8、χ=128 约 633 TFLOP，墙钟时间需要 cluster 实测。
新背景中的“2—7小时”是预算假设，不能当作已验证运行时间。

## 主谱法最需要避免的一个陷阱

全谱满足 `Tr(T^L)=Σ λ^L`；只保留几个特征值是谱近似，要覆盖两交换扇区及相关近简并簇的完整重数。
起始 block=4 不能保证找全重数大于4的精确简并；增加请求本征值数量本身不能修复起始空间不足。
增加保留数、检查最短使用 L 的稳定性有用，但不能假装已经证明不存在遗漏的大重数近简并簇。

固定 D、χ，若 T₁、T₂ 都只剩一个正实主根，则最终
`S₂(2L)=L[2lnλ₁(T₁)−lnλ₁(T₂)]+o(1)`，常数项自动为0。
这首先是有限谱的结果，不能直接据此判定已确认 algebraic gapless QSL 的类型。
需要随 χ、D 增加而稳定的长度窗口；“可以廉价算到 L=1000”不等于该长度已经具备物理精度。

## 实际执行 workflow

1. 读取每个 J₂、D 的原始 0713 two-C₃ 张量；保留原腿顺序与已有收敛环境，提取上述 env1 四 edge。
2. 先在可直接核对的小周长验证切口、χ 方向、Gram 正性及 `0≤S₂≤2L ln D`，再建立 matrix-free T₁/T₂。
3. 用非 Hermitian block Arnoldi/Krylov–Schur 求主谱，覆盖两 replica 扇区、重数与所需近简并簇；记录残差和内存。
4. 同一组谱计算全部目标 L；增加保留谱并检查 S₂、拟合量稳定，保留相位，不能只对模长求幂。
5. 在同一 D 下核对新增熵的 χ 稳定区间；对共同稳定的固定 L 比较或外推 D，再研究 L scaling。
6. 在该窗口检查线性项、常数及是否需要对数或其他有限长度修正；不先在有限 χ 下取最终大 L 极限。
